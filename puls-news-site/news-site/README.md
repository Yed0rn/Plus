# ПУЛЬС — демонстраційна новинна сторінка

Адаптивна статична сторінка українською мовою. Не потребує сервера, збірки чи встановлення залежностей.

## Запуск локально

Відкрийте `index.html` у браузері.

## Публікація на GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте в нього всі файли та папку `assets` зі структури цього проєкту.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Через хвилину GitHub покаже адресу опублікованої сторінки в цьому ж розділі.
